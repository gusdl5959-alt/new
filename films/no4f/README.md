# 4층은 없습니다

1998년 11월 3일, 3층짜리 고등학교 본관. 새로 온 야간 당직 선생이 순찰 증빙용 캠코더를 들고 「야간 순찰 수칙」대로 건물을 돈다.
아무도 없는 방송실의 차임, 불 켜진 3층 끝 교실, 그리고 '4층'으로 이어지는 계단.

- 길이 10분 · 4:3 VHS 캠코더 파운드 푸티지 · 한국어 자막(SDH) · 대사 없음
- 영상 생성 AI 없이 코드로만 만든 영화: three.js로 그린 공간, VHS 셰이더, 절차적 사운드 (numpy)
- [Lemo-Opuscar](https://github.com/lemomo-ai/lemo-opuscar)의 Liminal Found Footage 스타일(`backrooms`)로 제작
