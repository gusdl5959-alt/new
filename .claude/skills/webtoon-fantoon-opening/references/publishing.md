# 팬툰오프닝 업로드 문구

작품명, 영상 형식과 장르를 정확히 표현한다. 공식 애니처럼 쓰지 않는다. 무관한 인기 작품명·유행 태그로 채우지 않는다. 노출·조회수·구독자 증가를 보장하지 않는다.

## 최근 확정한 간단형

쇼츠용 간단 문구 기본 출력은 하나의 복사 가능한 블록이다.

1. 한국어 제목 한 줄.
2. 영어 제목 한 줄.
3. 일본어 제목 한 줄.
4. 빈 줄.
5. 해시태그 정확히 5개, 한 줄.

언어 이름, 설명 문장, 인사말, 가사, 추천 이유, 추가 태그를 붙이지 않는다. “종이 울렸다. 아직 수업은 끝나지 않았다. 팬메이드 애니 오프닝.” 같은 설명은 제외한다.

세 언어의 의미와 분위기를 일치시킨다. 작품마다 제목과 장르를 바꾸고, 공식 영문/일문명이 제공되거나 확인되었다면 사용한다. 없으면 자연스러운 작업 번역을 쓰되 공식 번역이라고 주장하지 않는다.

형식 예시:

[작품명]이 애니가 된다면?
What If [English title] Had an Anime OP?
[日本語タイトル]がアニメになったら？

다섯 해시태그는 작품명, 팬툰 브랜드, 적절한 영문 장르, 일문 형식, Shorts 등으로 관련성에 맞게 고른다. 공포 태그와 눈 이모지는 공포에 어울릴 때만 쓴다. 로맨스·코미디에는 해당 장르를 사용한다. 중복 태그를 제거한다.

세 줄을 한 플랫폼 제목 칸에 넣을 경우 현재 길이 제한에 맞게 줄이거나 제목/설명 위치를 구분한다. 다국어 문구 한 개를 세 영상 게시 요청으로 확대하지 않는다.

## 전체 업로드 문구 요청

추천 제목, 설명, 해시태그, 스튜디오용 쉼표 구분 태그를 제공한다. 제목은 작품명을 알아볼 수 있게 하고 “애니가 된다면?”, “팬메이드 OP” 등 실제 영상에 맞는 표현을 쓴다.

설명에는 작품과 다룬 범위, 팬메이드 여부, 제작 브랜드, 제공 음악의 이름/출처, 확인된 원작 크레딧과 공식 링크를 필요한 만큼 담는다. 작가, 저작권, 공식 명칭을 만들지 않는다. 실제 스포일러가 포함된 경우 범위를 표시한다.

실시간 검색 동향이나 현재 플랫폼 지침 검증은 허용된 경로로 공식 자료를 확인한다. 브라우저 접근 실패를 다른 도구로 우회하지 않는다. 번역과 단순 문구 수정은 매번 검색 작업으로 확장하지 않는다. 확인하지 못한 지침을 확인했다고 말하지 않는다.

문구 요청은 텍스트 전달 작업이다. 업로드·게시에는 별도 사용자 요청이 있어야 한다.
