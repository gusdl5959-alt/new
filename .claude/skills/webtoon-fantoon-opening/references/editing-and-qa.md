# 음악과 최종 편집·검수

## 제공 음악

실제 파일의 길이, 파형과 음악 구간을 확인한다(`scripts/analyze_song.py`). 가사 텍스트만 보고 추정한 타이밍을 싱크 완료라고 말하지 않는다. 도입·절·프리코러스·후렴·브레이크·마지막과 큰 타격음을 표시한다. 음성이나 기타의 작은 변화를 모두 드럼 비트로 취급하지 않는다.

사용자가 곡 전체를 주고 음악 편집을 요청하지 않았다면 원래 길이와 속도를 유지한다. 음악이 아직 없으면 장르·BPM 감각·구조·감정을 담은 수노 프롬프트를 요청 범위에 맞게 제공하고 인물·배경·빌런 샷을 먼저 준비할 수 있다. 곡이 도착하면 컷 길이와 전환점을 맞춘다.

가사는 실제 보컬 타이밍에 맞춰 SRT로 만든다(엔진의 `srt` 명령이 등록된 가사를 내보내고 시간 역전·겹침·길이 초과를 검사한다). 괄호 안 연출, 섹션 이름, 악기 지시는 제외한다. 기본적으로 가사를 영상에 삽입하지 않는다. 곡을 잘랐거나 시간을 바꿨다면 이전 SRT를 그대로 재사용하지 않는다.

## 기존 영상 활용

새 영상, 이전 개별 생성 영상, 재생성 영상, 기존 편집본, 음악, 로고를 목록화한다. 해상도·FPS·길이·내용·중복·확인 상태를 구별한다.

이전 편집본을 통째로 새 영상 앞뒤에 붙이지 않는다. 원본 클립을 우선 사용하고 필요한 경우 텍스트 없는 편집본의 좋은 구간만 가져온다. 자막 있는 버전과 혼동하지 않는다.

클립마다 정상 사용 구간을 기록한다. 중복은 해시와 화면으로 확인하고 원본을 지우지 않는다. 다른 파일명이라고 다른 장면으로 세지 않는다. 구성표와 실제 사용 소스의 대응 관계를 유지한다.

## 리듬

초반은 인물과 공간을 읽을 시간, 후렴은 행동과 반응, 브레이크는 긴장/관계의 여백, 마지막은 빠른 연타와 마무리로 설계한다. 장르마다 컷 수와 길이를 조정한다.

공포 액션은 괴물 준비/등장 → 접근/공격 → 인물의 회피·숨기·공포 반응을 연결한다. 괴물 얼굴만 반복하거나 반응만 늘리지 않는다. 반복 소스는 다른 정상 구간과 서사 기능이 있는지 확인한다.

컷을 기본으로 필요한 지점에 짧은 셔터, 방향성 와이프, 휩팬, 암전, 모양을 잇는 매치컷을 사용한다. 모든 컷에 전환을 넣지 않는다. 얼굴을 녹이거나 해부학이 흔들리는 보간으로 속도감을 만들지 않는다.

속도 변경은 행동이 실제 보이는 구간에 적용한다. 정적 샷을 늘리거나 과속으로 행동을 읽을 수 없게 만들지 않는다. 박자 연타 뒤에는 시선/공간을 읽는 시간을 준다. 컷 수만으로 빠른 템포를 주장하지 않는다.

단체샷은 모든 인물을 알아볼 수 있게 한다. 분할 합성 시 얼굴 크롭이나 잘못된 인물 조합을 피한다. 로고는 음악 주요 진입 또는 엔딩에서 읽을 시간을 주고 한국어 철자를 확인한다.

## 구현과 출력

기본 편집 도구는 번들 엔진 `scripts/opkit.py`다. 실행 순서는 [editing-workflow.md](editing-workflow.md), 컷 처방은 [editing-playbook.md](editing-playbook.md), 파라미터는 [opkit-api.md](opkit-api.md)를 따른다. 사용자가 다른 편집기를 지정하면 그 도구를 쓰되 아래 원칙은 그대로 적용한다. 이전 프로젝트의 절대 경로나 바이너리를 스킬에 고정하지 않는다. ffmpeg는 환경에서 찾아 쓰고(`scripts/tools.py`), 없으면 실제 사용 가능 여부를 확인한 뒤 설치는 사용자에게 묻는다.

출력 프레임 기준으로 타임라인을 기록한다. 공백·겹침, 원본을 벗어난 인/아웃, 속도 변경 후 길이를 확인한다. 서로 다른 FPS는 실제 타임스탬프 기준으로 맞춘다.

720p 요청이면 1280×720로 출력한다. 480p 소스의 출력 크기 조정과 AI 업스케일을 구별하고 원본이 720p라고 말하지 않는다. 사용자가 직접 업스케일할 예정이면 AI 업스케일을 임의 적용하지 않는다. 크롭은 얼굴·소품·중요 동작을 보존한다.

색 공간 변환을 실제 적용해 출력 표기와 픽셀을 맞춘다. 원작 조명을 유지한다. 원본 소스의 원치 않는 소리는 제거/비활성화하고 음악을 연결한다. 오디오 재인코딩 후 피크가 넘치지 않는지 확인한다.

## 완료 검수

실제 최종 MP4를 확인한다.

- 전체 프레임과 오디오 디코딩, 해상도, FPS, 길이, 끝부분.
- 의도하지 않은 검은 화면, 빈 레이어, 긴 정지/반복, 자막 있는 원본 혼입.
- 얼굴·손·괴물·소품이 바뀌는 구간, 인물 수와 단체샷 크롭.
- 음악 정렬, 중요한 전환점, 음량과 피크.
- 원곡을 유지했다면 파형 정렬, 편집했다면 실제 음악 편집 결과.
- 로고 가독성, 요청하지 않은 가사 삽입 여부.
- SRT 시간 역전·겹침·길이 초과와 실제 가사 싱크.

컷별 대표 프레임과 액션/전환 주변 연속 프레임을 실제 출력에서 검토한다(엔진의 `qa` 명령이 디코딩·검은 화면·정지·음량을 검사하고 완성 파일에서 프레임 시트를 뽑는다). 가능하면 정상 속도로 전체 재생 검수도 한다. 자동 디코딩, 대표 프레임 검토, 연속 액션 검토, 전체 재생은 다른 검수 수준이며 수행한 것만 보고한다.

문제를 고친 뒤 영향을 받은 실제 출력을 다시 확인한다. 파일명에 ‘최종’이 있다고 완료 처리하지 않는다. MP4 링크를 제공하고 원본과 이전 버전을 보존한다.
