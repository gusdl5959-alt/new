# 원작 확인과 오프닝 연출

## 원작과 레퍼런스 구분

자료를 세 가지로 기록한다.

- **원작 근거:** 공식 웹툰에서 직접 본 장면, 허용된 공개 이미지, 사용자 제공 원작 자료. 인물 외형과 괴물의 실제 형태·능력을 결정한다.
- **보조 설명:** 사용자 요약 영상, 위키, 리뷰. 조사할 대상을 찾는 데 사용하며 원작과 다른 내용은 그대로 확정하지 않는다.
- **연출 레퍼런스:** 다른 애니OP. 색, 샷 길이, 빌드업, 전환, 인물 등장 방식의 참고이며 새 작품의 사건 근거가 아니다.

선택한 회차만 확인했다면 그 범위를 기록한다. 모든 회차를 읽은 것처럼 말하지 않는다. 댓글과 팬 해석을 설정 근거로 삼지 않는다. 접속 제한을 우회하거나 대량 수집을 기본 작업으로 만들지 않고 필요한 공개 장면을 확인·캡처한다. 컴퓨터 유즈 전용 요청이면 조사도 그 경로를 따른다.

## 작품별 기준표

캐릭터마다 이름, 얼굴 윤곽, 눈, 앞머리/가르마, 머리색, 안경, 복장, 체형, 소품, 관계, 확인 회차와 이미지 경로를 기록한다. 긴장·정면·측면·전신 참조가 있으면 함께 모은다. 일반적인 미형 애니 얼굴로 바꾸지 않는다.

괴물/빌런마다 아래를 따로 확인한다.

- 얼굴·눈·입, 팔다리 수와 길이, 피부/재질, 체형, 복장과 크기.
- 고유 소품과 장소. 공, 지점토, 스피커 같은 대상이 그 작품에 실제 있다면 별도 에셋으로 관리한다.
- 원작에서 확인된 등장·이동·공격·표정·변화. 능력을 새로 만들지 않는다.
- 원작 등장 이미지, 다룰 부/회차, 동작을 만들기 위한 시작 포즈.

주요 인물과 위협 요소가 빠졌는지 목록으로 확인한다. 가능한 한 모두 등장시키라는 요청에는 짧은 인물 연타, 온전한 단체샷, 괴물별 짧은 행동 샷으로 대응한다. 인물 수가 많다고 각각 같은 정면 초상화를 길게 반복하지 않는다.

원작의 핵심 상징, 공간 구조, 소품 크기와 장치 형태도 기록한다. 다른 공포물의 익숙한 이미지로 대체하지 않는다. 확인이 부족한 대상을 세부 프롬프트로 먼저 단정하지 않는다.

## 팬이 알아보는 플롯

핵심 감정과 관계를 음악에 배치한다. 평온한 얼굴 → 위협의 흔적 → 다른 인물의 반응 → 괴물의 움직임 → 함께 버티는 인물 → 마지막 상징/로고 같은 구성을 참고하되 작품에 따라 갈등·로맨스·액션·성장으로 역할을 바꾼다.

구성표에는 컷 ID, 음악 구간, 등장인물/괴물, 원작 근거, 감정, 시작 이미지, 한 번의 행동, 샷 크기/시점, 예상 사용 길이, 다음 컷과의 연결을 넣는다.

소스는 최종 길이보다 넉넉하게 확보하되 장수 자체를 품질 목표로 삼지 않는다. 100컷×4후보처럼 수량이 지정되면 컷 수와 후보 수를 분리해 기록한다. 실제 생성하지 않은 후보를 수량에 넣지 않는다. 사용자가 고르겠다고 하면 후보를 보기 쉽게 제공하고 임의로 폐기하지 않는다.

## 장르별 움직임

| 장르 | 오프닝의 행동과 리듬 |
| --- | --- |
| 공포 | 공간의 이상 징후 → 괴물의 실제 접근/위협 → 인물의 움찔·회피·숨기·귀 막기. 고요한 구간과 빠른 공격 구간의 차이를 만든다. |
| 액션 | 준비·충돌·결과가 보이는 샷. 적과 주인공의 위치, 시선과 이동 방향을 연결한다. |
| 로맨스 | 시선, 손, 거리, 관계가 바뀌는 순간. 음악이 커진다고 근거 없는 공포·폭력을 추가하지 않는다. |
| 코미디 | 준비·예상·반전·반응. 작품 특유의 인물 관계와 표정을 활용한다. |
| 판타지/미스터리 | 세계의 규칙과 고유 상징. 의미 없는 입자나 풍경으로 인물·사건을 밀어내지 않는다. |

얼굴에 X, 이름 삭제, 빈자리, 인물 소멸을 사용하려면 원작의 운명과 요청된 스포일러 범위를 확인한다. 단순한 미장센을 이유로 사망을 만들어 내지 않는다.

## OP 레퍼런스 분석

제공 영상에서 전체 구조와 강한 구간을 확인한다. 정적 초상화의 길이, 반주 변화, 인물 연타, 빌런 등장, 단체샷, 전환 방향, 타이틀 노출을 관찰한다. 편집 원리를 새 작품의 인물·공간에 적용한다. 참조 화면·음악을 허락 없이 최종 소스로 넣거나 몇 장만 보고 전체 분석을 했다고 말하지 않는다.
